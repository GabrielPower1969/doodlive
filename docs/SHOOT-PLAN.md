# DoodLive · 实拍脚本（10 个场景 × 10 个镜头）

> 用途：应用商店截图与宣传图、30–60 秒宣传片、社交媒体、拿去给主日学 / 中文学校老师看的介绍材料。
> 写于 2026-10-24。⚠ 界面正在重新设计：**真人场景现在就可以拍，手机屏幕里的画面等新界面装好后用录屏补拍、后期替换**（见 §0.3）。

**阅读方式：** 每个场景一张表。“页面 / 状态”一列对应 app 状态机里的名字（见 [README §5](../README.zh.md#5-状态机什么时候停什么时候走)），拍之前照着那一列把手机切到对应画面。

## 0. 开拍前通用准备（每个场景都适用）

### 0.1 手机

| 项 | 做法 | 原因 |
|---|---|---|
| 装对版本 | `scripts/install-apk.sh <序列号>`，确认右下角指纹与要拍的版本一致 | 防止拍到旧界面（L28） |
| 屏幕常亮、满电 | 开发者选项“充电时不锁屏”，或一直插着电 | AR 拍到一半熄屏（L21） |
| 勿扰模式 | 打开，关掉所有通知 | 通知横幅会毁掉镜头 |
| 状态栏 | 满信号、满电、时间统一（例如 10:00） | 多张图拼在一起时时间不跳 |
| 手机壳 | 摘掉，或统一一个素色壳 | 画面干净 |
| 屏幕亮度 | 调到最高，关掉自动亮度 | 屏幕在画面里不发灰 |
| 擦屏幕 | 每个场景开拍前擦一次 | 指纹在逆光下特别明显 |

### 0.2 纸和道具

- 每个场景准备**两张涂好色的纸**（一张拍、一张备用），四个黑方块必须干净、不卷边。
- 至少准备三种涂法：孩子真实涂的（不完美才可信）、颜色鲜艳的“示范版”、主题纸（炙热 / 愤怒 / 神圣）各一张。
- 蜡笔 / 彩色铅笔：选颜色多、外观好看的一盒；拍前把断头削好。
- 桌面：浅色木桌或纯色桌布最好；避免花纹桌布（AR 和画面都会乱）。

### 0.3 屏幕画面怎么拍（两条路，推荐 B）

- **A · 直接拍屏幕：** 手机屏幕在画面里，真的亮着 app。优点是真实；缺点是反光、曝光难控制。
- **B · 实拍 + 录屏替换（推荐）：** 实拍时手机照常运行；同时用 `adb -s <序列号> shell screenrecord /sdcard/shot.mp4` 录下屏幕，后期把录屏贴回屏幕区域。新界面做好以后，只需补录屏，不用重拍孩子。

### 0.4 灯光与相机

- 主光：窗户侧光（上午或下午）最自然；晚上用一盏大的暖色柔光灯，放在侧前方 45°。
- AR 需要**光线足、桌面有纹理**；太暗时天使会抖或找不到纸（L16）。
- 相机：能拍 4K 的手机或相机都行；固定机位用三脚架，跟拍用稳定器。
- 画幅：每个镜头**同时拍横 16:9 和竖 9:16**（宣传片用横，商店截图和短视频用竖）。

### 0.5 孩子与隐私（硬规矩）

- 每个出镜孩子都要有监护人书面同意（写明用途：应用商店、网站、社交媒体）。
- 公开使用的画面里**不出现**：孩子全名、学校 / 教会名牌或标志、门牌、车牌、可识别的家庭住址。
- 非自家孩子优先拍手、背影、侧脸；正脸只用在拿到同意的孩子身上。
- 教会 / 学校场景要先征得负责人同意，并确认墙上海报里没有其他人的照片。

## 附 B · 拍摄顺序建议（省时间）

1. **先拍场景 9（棚拍）**：不需要孩子，一个下午拍完，同时检查纸和道具。
2. **再拍场景 1、2、6（家里）**：同一个家，按光线排：上午场景 1、傍晚场景 2、晚上场景 6。
3. **场景 5（户外）**：挑一个晴天下午。
4. **场景 3、4（教会 / 中文学校）**：要提前约，并拿到负责人和家长的书面同意。
5. **场景 7（节日）、场景 8（视频通话）**：布景比较多，单独排一天。
6. **场景 10（纯屏幕）**：新界面装好之后最后拍，顺便给前面所有场景补录屏。
