# Languages — eight languages, one app

Status: built 2026-11-22 (branch `feature/i18n-platform-layer`). Owner's brief: support the most-spoken languages:
English, Chinese, French, German, Japanese, Spanish, Modern Standard Arabic, Portuguese.

Source labels: `[A]` read in code, a model's own config, or measured on this Mac on 2026-11-22; `[D]` inference.

## 1. What is translated, and where it lives

| What | zh, en (unchanged) | fr, de, ja, es, ar, pt (new) |
|---|---|---|
| UI strings (169 keys) | `tools/i18n/strings.json` | same file, one field per language |
| Story title, bookshelf blurb | `assets/stories.json`, `assets/library.json` | `assets/<story>/i18n.json` |
| Chapter titles, spoken lines | `assets/<story>/timeline.json` | `assets/<story>/i18n.json` |
| Voices | `assets/<story>/audio/voice/{zh,en}/` | `assets/<story>/audio/voice/<lang>/` (no Arabic, §4) |

Generated files (never edit by hand):

| Tool | Writes |
|---|---|
| `tools/i18n/merge.py` | folds `tools/i18n/staging/<lang>.json` into `strings.json` and `assets/*/i18n.json`; writes `unity/Assets/DoodLive/Resources/i18n_stories.txt` (the app's story-text table) |
| `tools/gen_i18n.py` | `unity/Assets/DoodLive/Scripts/L10n.cs`, `web/i18n.js` |
| `tools/make_fonts.py` | font subsets, including Noto Sans JP and Noto Sans Arabic |
| `tools/story/voice_i18n.py` | voices for fr de ja es pt (Qwen3-TTS VoiceDesign, local) |

Adding a language: add it to `LANGS`/`NAMES` in `gen_i18n.py`, `EXTRA` in `merge.py`, the face in
`ARColoringController.UI.cs FontOf`, and (if Qwen3-TTS speaks it) `voice_i18n.json`. Then translate into a staging
file and run the four tools.

## 2. How the app chooses

- **Default**: the phone's system language when it is one of the eight, else English (`L10n.FromSystem`). The choice is
  remembered (`PlayerPrefs "lang"`).
- **Picker**: the language chip on the bookshelf and the "Language" row in the grown-ups panel open a modal picker; each
  language is written in itself (`中文 English Français Deutsch 日本語 Español العربية Português`).
- **QA**: `adb shell am start ... --es lang fr` starts in a language (`Platform.Native.Args`).
- **Look**: Chinese and English keep the original two-line look (Chinese big, English small). The other six show one
  line in their own language; nothing falls back to Chinese, a missing string falls back to English.

## 3. Fonts and scripts

| Language | Face | Why |
|---|---|---|
| zh | ZCOOL KuaiLe | unchanged |
| en | Fredoka (text), ZCOOL KuaiLe (buttons) | unchanged |
| fr de es pt | Fredoka everywhere | ZCOOL KuaiLe has no accented letters (é ü ñ ç ã…) `[A · cmap check]` |
| ja | Noto Sans JP Bold | kana + the kanji the translation uses, 304 KB subset `[A]` |
| ar | Noto Sans Arabic Bold | has the Presentation Forms-B code points (141) that the shaper needs `[A · cmap check]` |

**Arabic in IMGUI.** Unity's IMGUI has no text shaping and draws left to right. `Scripts/ArabicText.cs` (pure C#, no
library) turns each letter into its isolated / final / initial / medial presentation form, joins lam + alef, and puts
the line in visual order (Latin and digits keep their own direction). Paragraphs (subtitles, blurbs) are broken into
lines first (`ArabicText.Wrap`), because IMGUI's own wrap would put the end of the sentence on the first line.
Limits: harakat are dropped when drawn; the screen layout is not mirrored (buttons stay where they are) `[D · fine for
a first version; a full RTL layout is a later step]`.

## 4. Voices

Qwen3-TTS speaks Chinese, English, German, Italian, Portuguese, Spanish, Japanese, Korean, French and Russian, and **not
Arabic** `[A · talker_config.codec_language_id in the model's config.json, 2026-11-22]`. So:

| Language | Voice |
|---|---|
| zh, en | unchanged (existing casts) |
| fr, de, ja, es, pt | Qwen3-TTS VoiceDesign, one designed voice per role (`tools/story/voice_i18n.json`) |
| ar | none: the story plays with Arabic subtitles at the original timing |

Every role's voice is described once in English (who is speaking), plus "a native <language> speaker"; the line's acting
note (`dir` in the timeline) is added per line. Each take is transcribed locally (mlx-whisper) and compared with the
text; up to 3 takes, the first that passes is kept (`report-<lang>.json` lists word error and length per line, so the
lines to listen to are easy to find). Nothing is sent anywhere.

**First full run, 2026-11-22** `[A · report-<lang>.json]`: 1,950 lines (390 × 5) in 2 h 29 min on this Mac
(`--takes 3 --max-try 2`). The first take passed for 361 fr, 372 de, 380 ja, 371 es and 368 pt lines. 76 lines stayed
above the word-error limit (fr 23, de 17, ja 5, es 13, pt 18); nearly all are stutters, sneezes and sound words that
whisper cannot spell (`es_12g` "Mar... Mar... MARDOCHÉE", `ex_32` sneeze). Listen to those first.

**Storage.** Git keeps the 96 kbps MP3s and the two JSON files per language (about 27 MB per language). The WAVs that
Unity imports are about 1 GB and stay out of git: after a fresh clone run `tools/story/voice_wavs.sh` before the first
build. To redo lines: `.venv-voice/bin/python -u tools/story/voice_i18n.py --langs fr --stories esther` (finished lines
are skipped by signature; `--force` redoes them).

Translations were written by Claude (2026-11-22) with Bible-name conventions per language (Louis Segond, Luther /
Gute Nachricht, 新共同訳, Reina-Valera, Van Dyck, Almeida / NTLH). **A native speaker has not checked them yet.** Open
questions the translators raised are in `tools/i18n/REVIEW.md`.
