# Rules — every role, every pack

| # | Rule | Why |
|---|---|---|
| R1 | **Touch only your role's files** (pack `CONTRACT.md` §1). Shared files (`assets/stories.json`, `assets/library.json`, `tools/i18n/strings.json`, `DGFxEffects.cs`) are generated by `tools/story/merge_packs.py`; never edit them by hand. | Several sessions work in this repo at once. |
| R2 | **The repo gets code and data; the process goes to the owner's Hours vault.** No diaries, chat logs, reference-film screenshots or transcripts in the repo. | Public repository. |
| R3 | **Do not commit or push** unless the lead tells you. The lead commits one pack as one commit with a plain-English message. | One clean commit per pack. |
| R4 | **Only the lead runs Unity or uses the phone, and only after asking the owner and every other active session.** Never `adb install` by hand; never `adb kill-server`; never pipe `scripts/build-apk.sh`. | A Unity Android build restarts adb and cuts another session's recording (LESSONS L52). |
| R5 | **The kit is shared.** Put story-specific code in your pack script. Move a function into `pipeline/story_kit/` only when a second pack needs it, and then the packs already using it must regenerate byte-identical. | `docs/STORY-KIT.md`. |
| R6 | **Words come from Scripture, in our own paraphrase, with the verse.** Do not quote any Bible translation at length and do not copy lines, character designs, shots or melodies from any film. | Copyright; the reference viewing lends costume logic and mood only. |
| R7 | **Voices and music must be licensed for commercial use.** Chinese and English voices: Qwen3-TTS (Apache-2.0), run on this Mac. **Do not use `edge-tts`.** Music: our own synth engine (`music_kit.py`). Record engine and licence per clip in `sources.json`. | The app will be sold in stores. |
| R8 | **Child-friendly.** Follow the pack's "child-friendly choices". Nothing frightening lasts longer than a few seconds; villains are comic; no blood, no death on screen. | Ages 4-10. |
| R9 | **Every colourable region ≥ 6 mm on the A4 print.** Smaller parts become fixed-colour detail lines or share a neighbour's region. | A child must be able to colour it. |
| R10 | **Check with your eyes.** Render, open the PNG, look, fix. A passing script check is not enough. | Most past defects were visible in the first preview. |
| R11 | **Disk and scratch.** Scratch in `/tmp/<id>_<role>/`; delete it when done; do not keep render sequences or rejected takes. | The Mac has run out of disk three times. |
| R12 | **Say what is not done.** End every report with what is weak or unverified. Do not write "done" for something you did not check. | The owner decides from the reports. |
| R13 | **Stay in the contract.** Ids, bone names, clip names, node names, cue and effect ids are fixed. If one must change, stop and tell the lead; do not rename on your own. | Five roles read the same names. |
| R14 | **English in the repo** (code, comments, docs, commit messages). Line text is bilingual in `story.py` only. | Repo convention. |
